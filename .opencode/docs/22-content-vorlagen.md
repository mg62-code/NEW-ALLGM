# Content-Generierungs-Vorlagen pro Seitentyp

## Startseite (Homepage)

### Struktur
1. Hero-Banner (Headline + Subline + 2x CTA)
2. USPs (3-4 Vorteile mit Icons)
3. B2C vs B2B Auswahl
4. Markenhersteller (Logo-Leiste)
5. Top-Angebote (Produkt-Grid)
6. Vertrauenssignale (Testimonials, Zahlen)
7. Blog-Vorschau / Ratgeber
8. Newsletter-CTA
9. Footer (Kontakt, Social, Legal)

### Textvorlage Hero
```
Headline: [Kernnutzen in 5-8 Worten]
Subline: [1 Satz Erklaerung fuer Wen]
CTA 1: [Primärer Aktionsbutton]
CTA 2: [Sekundaerer Aktionsbutton]
```

### Textvorlage USP
```
Icon/Emoji | Ueberschrift (3-5 Worte) | Beschreibung (1 Satz)
```

---

## Produktkategorie (z.B. Solarmodule)

### Struktur
1. Kategorie-Header (Titel + Beschreibung)
2. Filter/Sortierung
3. Produkt-Grid mit Bild, Titel, Preis, CTA
4. Vergleichstabelle (optional)
5. FAQ zur Kategorie
6. Verwandte Produkte

### Textvorlage Kategorie-Header
```
Ueberschrift: [Produktkategorie] bei GE-Solar
Beschreibung: 2-3 Sätze ueber die Kategorie, Vorteile, fuer wen geeignet
```

---

## Produktseite

### Struktur
1. Produktbild (gross, zoombar)
2. Titel + Kurzbeschreibung
3. Preis + MwSt.-Hinweis
4. SKU / Verfuegbarkeit
5. In den Warenkorb Button
6. Tabs (Beschreibung, Technische Daten, Versand)
7. Verwandte Produkte
8. Produkt-Bewertungen

### Textvorlage Beschreibung
```
Absatz 1: Was ist das Produkt? (2-3 Sätze)
Absatz 2: Vorteile fuer den Kunden (3-4 Bullet Points)
Absatz 3: Technische Kernmerkmale (5-6 Bullet Points)
Absatz 4: Lieferumfang / Hinweise
```

---

## Über Uns

### Struktur
1. Story-Header (Wer sind wir?)
2. Gruender/Geschaeftsfuehrer (Bild + Text)
3. Kernwerte (3-4 Werte mit Erklaerung)
4. Zahlen und Fakten (gegruendet, Kunden, Leistung)
5. Team-Foto (optional)
6. CTA (Kontakt aufnehmen)

### Textvorlage
```
Headline: Solar mit Leidenschaft – Seit [Jahr] in [Ort]
Story: 3-4 Absaetze ueber Gruendung, Motivation, Vision
Kernwerte: [Wert] | [Kurzbeschreibung]
```

---

## Kontakt

### Struktur
1. Kontaktformular (Name, E-Mail, Telefon, Nachricht, Dropdown)
2. Adressdaten (Strasse, PLZ, Ort)
3. Telefon + E-Mail
4. Oeffnungszeiten
5. Karte (Google Maps Embed)
6. Social-Media-Links

### Formular-Felder
```
- Name (Pflicht)
- E-Mail (Pflicht)
- Telefon (optional)
- Anliegen (Dropdown: Privatberatung, Gewerbeangebot, Sonstiges)
- Nachricht (Pflicht)
- Datenschutz-Checkbox (Pflicht)
```

---

## Ersparnisse / Rechner

### Struktur
1. Headline (Sparen Sie X% mit Solar)
2. Interaktiver Rechner oder statische Tabelle
3. Beispielrechnungen (Balkonkraftwerk, 5kW, 10kW)
4. CTA (Jetzt anfragen)

### Textvorlage
```
Headline: So viel sparen Sie mit Solarstrom
Einleitung: 2-3 Sätze ueber Rentabilitaet
Beispiel 1: Balkonkraftwerk 800W - [Jahresertrag] kWh - [Ersparnis] EUR/Jahr
Beispiel 2: PV-Anlage 5kW - [Jahresertrag] kWh - [Ersparnis] EUR/Jahr
CTA: Berechnen Sie Ihr individuelles Einsparpotential
```

## Allgemein / Ratgeber

### Struktur
1. Headline (Thema)
2. Einleitung (Warum relevant?)
3. Inhaltsverzeichnis (optional)
4. Hauptteil (3-5 Abschnitte mit H2/H3)
5. Zusammenfassung
6. CTA (Produkte entdecken)
7. Verwandte Artikel

---

## Blog-Artikel

### Struktur
1. Titel + Featured Image
2. Einleitung (Hook, 2-3 Sätze)
3. Hauptteil (H2-H6 gegliedert)
4. Fazit (2-3 Sätze)
5. CTA
6. Tags + Kategorien

### SEO-Checkliste pro Artikel
- [ ] Titel < 60 Zeichen
- [ ] Meta-Beschreibung < 160 Zeichen
- [ ] H1 = Titel
- [ ] Erstes Keyword in ersten Absatz
- [ ] 1-2% Keyword-Dichte
- [ ] Mindestens 300 Worte
- [ ] Internal Links zu Produkten
- [ ] Alt-Tags bei Bildern
